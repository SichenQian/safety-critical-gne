# Theorem 3 局部证书的可计算构造

本文档对应本次冻结稿 Theorem 3 及其附录，数值由 `matlab/theorem_certificates.m` 生成。它给出保守的充分条件，不声称计算出最大吸引域。解析不等式在双精度中求值，未使用有向舍入区间算术。

## 1. 平衡点与矩阵范数

游戏矩阵为 B=1.15 I−0.03 11ᵀ，F(y)=(B⊗I₂)y−p。因此 μ=1，l=1.15；扩展伪梯度每个玩家使用其独立估计块，对应块行范数相同，tilde l=√(1.12²+4×0.03²)。求解 By*=p 得原稿目标位置，未重新指定目标。

在目标处逐项检查：几何屏障和扩展屏障为正、dij*≠dc、保留碰撞行 K1 h*−DeltaInt>0、所有障碍行 K1 h*−DeltaObs>0、连通行 K1 hC*−DeltaC>0。严格可行时，正则化 QP 唯一原始最优为 (u_nom,0)，乘子为0；在平衡点 u_nom=0。因此全平衡为 (1⊗y*,0,0,0,0)。

## 2. 全局导数界与局部球

记边变量 t=d²/(dc²−d²)≥0。支持内部 w=e^(−t)，边向量导数界可取 G_e=8/(e dc)，H_e=[8/e+4(256/e³+54/e²)]/dc²；支持外权重与所有导数为0。五节点完全图有125棵生成树。

每棵树的关联矩阵谱范数≤√5。记 S=Σ t_e，则 Σ t_e(1+t_e)³≤S(1+S)³。由乘积法则，当前归一化证书 hC=(5/512)Σ_T Π_e w_e−0.04 满足

- G_h=(625/512)(2√5/dc)√[s(1+s)³]e^(−s)，s=(1+√3)/2；
- H_h=(625/512)(8H_e+24G_e²)。

在慢误差球 ||e_θ||≤r 内，真实或每个估计位置偏差≤r，真实速度偏差≤r，估计速度范数≤(1+8c)r，物理漂移范数≤(γ+8c)r，名义输入范数≤tilde l r。由于 L(y)(1⊗y*)=0，这些界无需用非零平衡位置乘上图导数。

取 d_max=max_active d*+√2r，o_max=max_i,k ||y_i*−o_k||+r。代码依次建立碰撞、障碍、连通性 nominal-row slack 下界；全部考虑漂移、K2速度项、Hessian项、tightening和实现中的0.06/0.1屏障缩放。mismatch列保持原始值，不被误描述为整行统一缩放。

碰撞单边分配行的未加权下界为

    s_int = [K1(h_int,min*−2 d_max √2 r)−DeltaInt]/2
            −2 d_max(γ+8c+tilde l+K2)r−2r².

保留边最小权重取 chi_min=exp[−d_max²/(dc²−d_max²)]，最终该行下界为0.06 chi_min s_int。障碍行使用对应单体界；连通行下界为

    s_c = [K1(hC*−G_h r)−DeltaC]/5
          −G_h(γ+8c+tilde l+K2)r−H_h[(1+8c)r]²/5,

最终乘0.1。耗散行在 r<nu/2 内恰为常数−deltaP，系数为0。

同时检查 λ2*−2m√2G_e r>lambdaLower、√2r<min|d*−dc|、局部几何屏障与 ψ1=dot h+alpha1 h 的显式下界为正。若任一条件不通过，代码将 r 减半；通过的闭球定义 Theta0。

## 3. 快误差管道与复合 Lyapunov 子水平集

用每类完整约束行（包括 mismatch 列）的范数上界 B_row 和 nominal slack s_row 取 eta_I=min s_row，并选

    r_loc ≤ min(10^-3, 0.5 min_rows[(s_row−eta_I/2)/B_row]).

由三角不等式，整个管道中 g0≤−eta_I/2。零系数耗散行无需参与除法。全矩阵范数上界 Bbar 用各类行范数的平方和求得。

令 h0=min(1,xi)，选择 kappa>Bbar² r_loc/(eta_I h0)，从附录原式计算 c_f=min{h0/2,kappa eta_I/(2r_loc)−Bbar²/(2h0)}。随后以附录 Q 矩阵的 Schur 补计算 epsilon 上界，确认实际 epsilon 严格小于上界且 λmin(Q)>0。没有将 c_f 任意置为一个正数。

慢 Lyapunov 的上下界由 P_k=[[k gamma,k],[k,1]]/2 和非自身估计块系数 k/2 直接求得，分别记 m_s,M_s；快 Lyapunov 上下界记 m_f,M_f。选择

    rho = 0.5 min(m_s r², sigma m_f r_loc²),
    r_Theta1 = sqrt[rho/(2M_s)],
    r_f = sqrt[rho/(2 sigma M_f)].

于是慢球和快球的笛卡尔积均满足 V_c≤rho，且子水平集严格包含在 Theta0 内部与 ||e_f||<r_loc 中。这一步把稿内存在性邻域构造为一个具体、保守的充分邻域。

## 4. 实验初始化与结论范围

慢扰动使用固定向量 sin(sqrt(2)(1:60))，归一化为0.75 r_Theta1，包含位置估计和速度分量。输入初始化为当前 u_nom，保留 mismatch 第一分量设0.5 r_f，其余为0；全部乘子设0。最终逐一重新计算实际慢/快范数、nominal/actual行裕量及 V_c(0)，避免依赖赋值意图。

本次 dc=2.2 时，目标处边 (3,4) 的距离为2.3，属于局部省略边；其两条约束行15、16及 mismatch 列15、16均在局部误差定义中省略。全部乘子从0初始化，省略行乘子在输出上始终为0。其余目标边保留，离支持边界有正间隔。

证书与数值曲线有不同作用：前者依据解析充分条件构造初值，后者检查相同方程的有限精度实现。曲线拟合斜率不替代理论衰减下界，也不说明远初值进入该局部域。
